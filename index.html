Plex Artwork Studio

macOS-friendly local artwork editor · Poster & background

1 · Artwork & discovery

TMDB provides title, poster, backdrop, and production-company discovery. Search needs internet and your own TMDB token. Without a token, open the public search links below.

Choose specific artwork

TMDB alternatives and Fanart.tv artwork (with API key). Select a thumbnail to load the original-resolution image. Artwork availability depends on TMDB contributors.

Additional artwork sources

Open source searches in a new tab, then download and upload artwork. These sources are not directly indexed by this browser-only build; some require accounts or restrict downloading.

Local artwork repository

Choose the parent folder on your Mac. PAS creates organized folders for posters, backgrounds, logos, downloaded artwork, and projects. Compatible browsers can export directly to the selected repository.

No repository selected. Use Chrome or Edge on macOS for direct folder access; Safari can use normal downloads.

2 · Company logo library

Select a production company found through TMDB to automatically retrieve its available logo, or upload a transparent logo. Logos persist in this browser's local storage.

3 · Awards

Search awards reference pages (including Golden Raspberry / Razzie awards), then add verified wins or nominations. Automated verified award ingestion is not available in this local build.

4 · Remove original text

Paint over lettering to remove it using a local pixel-repair method. This is not generative AI inpainting; complex areas may require an external editor.

Repair uses surrounding pixel colors and can blur large regions. For precision, use a dedicated inpainting application.

5 · Composition & export

All image processing and exports occur locally. Browser storage may be cleared by browser settings. Source configuration is available under Artwork Sources & Accounts. TMDB and Fanart.tv support direct galleries when authorized. Other providers remain external until approved programmatic access is available.

Live artwork preview

The exported PNG is generated at the exact selected dimensions. Company logos stay inset from the upper-left edge; awards appear centered at the bottom.

Artwork Sources & Accounts

Configure source preferences and API credentials. This browser version supports direct TMDB artwork discovery. Other sources are links unless a documented API integration is available. Account passwords are not requested or saved.
